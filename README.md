# C++ Multi-threaded Task Runner

> **Learning project** — built as coursework / for learning. Kept here as a reference and a record of the work.

A demonstration of concurrency and thread synchronization.

## Features
- **Parallelism**: Runs 8 simultaneous threads to showcase multi-core utilization.
- **Thread Safety**: Uses `std::mutex` to prevent data races.
- **Modern C++**: Implemented using the C++11 `<thread>` library.
